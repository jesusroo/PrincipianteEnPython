🐍 Mis Primeros Pasos en Python
¡Bienvenido! Este repositorio es un espacio personal donde guardo mis primeros códigos, ejercicios y proyectos básicos utilizando Python.

El objetivo de este espacio es registrar mi proceso de aprendizaje, dominar la sintaxis del lenguaje y construir una base sólida en lógica de programación y desarrollo de software.

🚀 ¿Qué vas a encontrar aquí?
Aquí iré subiendo scripts sencillos y programas ideales para nivel principiante, tales como:

🧮 Ejercicios de Lógica: Calculadoras básicas, conversores de unidades y juegos de adivinanzas.

🔄 Estructuras Fundamentales: Prácticas usando variables, condicionales (if, else) y bucles (for, while).

📊 Manejo de Datos: Listas, diccionarios y manipulación básica de textos o números.

🛠️ Herramientas
Lenguaje: Python 3

Propósito: Práctica académica y desarrollo de lógica de programación.
